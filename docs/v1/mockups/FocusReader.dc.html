왜 √dk로 나눠?
q와 k의 각 성분이 평균 0, 분산 1인 독립 변수라고 보면 내적의 분산은 dk가 돼요. dk가 크면 값이 커져서 softmax가 한 위치에 몰리고 기울기가 거의 0이 돼요. √dk로 나누면 분산이 1로 맞춰져요.
base 모델을 재현하려면 뭐가 필요해?
논문에 나온 값만 모으면 이래요.
  • N=6, d_model=512, d_ff=2048, h=8
  • Adam 0.9/0.98/1e-9, warmup 4000
  • P_drop 0.1, ε_ls 0.1
  • P100 8장에서 100K step, 약 12시간
GPU가 1장이면 같은 배치 크기를 맞추려고 gradient accumulation이 필요해요. 학습 시간은 논문 값보다 길어질 거예요. 실험 설계 초안 만들기
식 (1) · §3.2.1이 수식을 단계별로 풀어줘
  1. QKT · 모든 쿼리와 키 쌍의 내적 점수 행렬을 만들어요
  2. ÷ √dk · 점수 크기를 맞춰요
  3. softmax · 각 쿼리 행마다 합이 1인 가중치로 바꿔요
  4. × V · 가중치로 값 벡터를 섞어 출력을 만들어요
