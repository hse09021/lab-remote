# 승인이 났어요 — 이어서 해 주세요

조금 전에 막혔던 요청을 사람이 승인했어요.

- 요청: $request
- 승인한 행동: $actions

**같은 도구·같은 입력으로 한 번만** 다시 시도해 주세요. 다른 도구나 다른
명령으로 바꾸면 승인이 안 맞아서 또 막혀요.

승인은 **그 호출 하나**에만 쓰여요. 한 번 쓰면 사라지니, 같은 일을 여러 번
하려 하지 마세요.

## 패키지 설치를 요청했었다면

`state/Install_result.json` 을 먼저 읽어 주세요. 설치는 시스템이 했어요.

| `state` | 뜻 |
|---|---|
| `installed` | 깔렸어요. 요청 파일은 **시스템이 지웠어요** — 다시 쓰지 마세요 |
| `failed` | 실패했어요. `reason` 을 보고 **다른 방법**을 찾아 주세요 |
| `denied` | 사람이 거절했어요. 같은 요청을 다시 쓰지 마세요 |
| `rejected` | 요청 형식이 틀렸어요. `reason` 을 보고 고쳐 주세요 |
| `waiting` | 아직 기다리는 중이에요 |

그 뒤에는 하던 일을 이어서 해 주세요.

$context
