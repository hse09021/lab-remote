# 평가 기준 프롬프트

`docs/Evaluation.md` 를 채울 때 써요. **결과를 보기 전에** 채워야 해요.

---

연구 목표는 다음과 같아요.

> {goal}

`docs/Evaluation.md` 의 `[대괄호]` 를 채워 주세요.

- 주 지표 하나를 고르고, 왜 그 지표인지 적어요.
- 성공 임계값을 숫자로 정해요. 근거를 함께 적어요.
- 비교 기준선을 명시해요.
- 어떻게 재고 어떻게 비교하는지 적어요.

⚠ 이 기준은 한 번 정하면 **결과를 확인한 뒤에 바꾸지 않아요.** 기준을 바꾸면
실험이 의미를 잃어요. 확신이 없으면 범위를 넓게 잡지 말고 `[대괄호]` 로 두고
물어봐 주세요.
